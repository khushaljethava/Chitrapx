# Sub-project 3 Implementation Plan: Editor

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Edit any project in the browser with undo, autosave and conflict safety.
**Architecture:** Pure commands over ChitrapxDoc with Immer patches; Zustand store; overlay above the shared StaticArtboard; optimistic-concurrency save API.
**Tech Stack:** Zustand, Immer, IndexedDB (native), existing renderer.
**Spec:** `docs/superpowers/specs/2026-10-02-sp3-editor-design.md`

## Global Constraints
- The document changes only through `apply(command)`; components never mutate it.
- Canvas renders through `StaticArtboard` (same as export).
- Pointer events only; keyboard shortcuts ignored while a form field has focus.
- No em or en dashes in user-facing copy.

## Review Focus
1. **Stale revision after conflict:** "Keep mine" must re-save on the server's revision, never loop on 409. Pinned in Task 1 and Task 5.
2. **Oversized or malformed save:** a 6 MB or invalid doc gets 413 or 400 and leaves the stored doc untouched. Pinned in Task 1.
3. **Undo across locale edits:** undo of an override edit restores the override map exactly. Pinned in Task 2.
4. **Deleting the selected board:** selection and active board stay valid (never point at a removed id). Pinned in Task 2.
5. **Typing in the inspector while shortcuts are bound:** Backspace in a field never deletes the element. Pinned in Task 6.
