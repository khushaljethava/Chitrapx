# Changelog

What changed in Chitrapx, newest first. Each release heading reads `## [version] - YYYY-MM-DD`, with `Added`, `Changed` and `Fixed` sections; edit this file and rebuild to publish a new entry on `/changelog`.

## [Unreleased]

### Added
- Teams: invite people by link as admin, editor or viewer, within your plan's seats, and switch between workspaces
- Share a read-only link to a project; signed-in visitors can copy it into their own workspace
- Comments on boards and elements, with replies, resolve, @mentions and in-app notifications
- A notice when a new version is live, with a Refresh button that saves your work first
- This changelog, and a privacy page
- Optional, cookieless usage counts, asked for once and changeable from Cookie settings
- Community templates: share a project, browse what others shared, and start from it in one click
- Export and version history dialogs close with Escape and keep keyboard focus inside

### Changed
- Named versions are kept up to 50 per project and always listed
- Adding several images at once is one undo step

### Fixed
- Clicking a group no longer selects its hidden layers
- Renaming a layer keeps the name when you click away
- Restoring a version works even when your latest changes cannot be saved

## [0.11.0] - 2026-10-05

### Added
- Translations table with inline edits, CSV and JSON import and export
- AI translation from any language, with a per-app glossary
- Right-to-left languages, with optional mirrored layouts
- A saved AI brief per app, app-type presets and AI feature chips for the Google Play feature graphic
- Competitor reference board with per-image analysis

## [0.10.0] - 2026-10-05

### Added

### Changed
